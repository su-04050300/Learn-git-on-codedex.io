建立一個新的remote repo on gitHub
>> Learn-git-on-codedex.io


建立一個local repo 
指令: git init
>>應該是要先建立一個local目錄，並cd 到目錄下指令建立.git檔案


將remote 跟local 串接
指令: git remote add origin <repository_url>
git remote add origin https://github.com/su-04050300/Learn-git-on-codedex.io.git


改由ssh 連線
>>先確認有ssh 金鑰，確認或建立好後複製公鑰

指令: ls -al ~/.ssh # 確認有無ssh
>>若有看見id_ed25519代表已經有金鑰了

建立新的ssh金鑰
指令: ssh-keygen -t ed25519 -C "你的GITHUB 註冊信箱"
>>執行後會要確認路徑，照預設的就可以了。會問要不要設定密碼自行決定

將ssh 加入ssh-agent
指令: eval "$(ssh-agent -s)"
指令: ssh-add ~/.ssh/id_ed25519

複製公鑰內容
指令: pbcopy < ~/.ssh/id_ed25519.pub

將公鑰貼到gitHub


將remote 跟local 串接
指令: git remote set-url origin git@github.com:su-04050300/Learn-git-on-codedex.io.git

設定git branch 
指令: git branch -M main


設定git ignore
cat > .gitignore << 'EOF'
build/
dist/
*.spec
EOF


查看目前有什麼檔案
指令: git status


把所有檔案夾加進git 表
指令: git add . # 所有檔案
指令: git add example.txt # 加入指定檔案example.txt
指令: git add *.html # 加入同個檔案類型


local commit
指令: git commit -m "這裡寫上commit備注"


push 上 gitHub 
指令: git push -u origin main # 第一次push
指令: git push # 第二次push


逐行看具體改了什麼
指令: git diff

開新的branch
指令: git checkout -b [NEW BRANCH NAME]

透過指標轉換 來選擇commit 的branch
指令: git checkout [NAME]


merge
指令: git merge [BRANCH NAME]

git rebase
rebasing 是 merge branch 的第二種方法。rebasing 就是取出一連串的 commit，"複製"它們，然後把它們接在別的地方。
指令: git rebase [BRANCH NAME]
要注意rebase的對象，讓HEAD留在要被複製的Branch 指令的Branch 是目的地


head 
當在做checkout branch 的時候head 一直都是跟著Branch 走，現在要分開就下指令check 節點就行
例如現在main branch 在C4點，要在C4點分離出head
指令: git checkout c4

相對引用＾
這個就是在Branch 上不確定節點名稱，但知道是前幾個節點，像指標一樣
例如 要head 要在bugFix 的前兩個節點
指令: git checkout bugFix^^ # head 去指向Bugfix 前兩個節點

相對引用～
就是覺得^^^^ 打太多很不好辨識，用~加數字
git checkout bugFix^^ = git checkout bugFix~2

git branch -f <branch> <commit>
-f 是 force 的意思，會強制把已經存在的分支指標移到指定的 commit 上，不管原本 main 指向哪裡
