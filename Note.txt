建立一個新的remote repo on gitHub
>> Learn-git-on-codedex.io

建立一個local repo 
指令: git init
>>應該是要先建立一個local目錄，並cd 到目錄下指令建立.git檔案

將remote 跟local 串接
指令: git remote add origin <repository_url>
git remote add origin https://github.com/su-04050300/Learn-git-on-codedex.io.git

設定git branch 
指令: git branch -M main

設定git ignore
cat > .gitignore << 'EOF'
build/
dist/
*.spec
EOF

查看目前有什麼檔案
指令: git status


把所有檔案夾加進git 表
指令: git add . # 所有檔案
指令: git add example.txt # 加入指定檔案example.txt
指令: git add *.html # 加入同個檔案類型


第一次commit
指令: git commit -m "這裡寫上commit備注"
